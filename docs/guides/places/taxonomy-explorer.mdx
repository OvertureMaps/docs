# Taxonomy Explorer

Explore the Overture Places taxonomy. Click a category to drill into it, search
to find one by name, and use the download links to take the release away as CSV.

See [Places Taxonomy](./taxonomy.mdx) for what the `taxonomy` and
`basic_category` properties mean and how to use them.
