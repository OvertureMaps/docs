# TravelMode

Enumerates possible travel modes.

Some modes represent groups of modes.

- `motor_vehicle` - Includes car, truck and motorcycle
- `car`
- `truck`
- `motorcycle`
- `foot`
- `bicycle`
- `bus`
- `hgv`
- `hov`
- `emergency`
