# SegmentSubtype

Transportation segment subtype classification.

## Values

- `road` - A segment of the road network, travelled by motor vehicles, cyclists, pedestrians, etc.
- `rail` - A segment of the railway network, travelled by trains, trams, and other rail vehicles.
- `water` - A segment of the navigable water network, travelled by vessels such as ferries and boats.
