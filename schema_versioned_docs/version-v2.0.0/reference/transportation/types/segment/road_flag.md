# RoadFlag

Simple flags that can be on or off for a road segment.

Specifies physical characteristics and can overlap.

## Values

- `is_bridge`
- `is_link` - Deprecated: will be removed in a future release in favor of the `link` subclass
- `is_tunnel`
- `is_under_construction`
- `is_abandoned`
- `is_covered`
- `is_indoor`
